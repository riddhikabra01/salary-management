# Salary Management

Web application for an HR manager to manage salary data for about 10,000 employees
across multiple countries and to see how the organisation pays its people.

See `docs/requirements.md` for scope and decisions.

## Structure
- `backend/` Spring Boot service (Java 17, Maven)
- `frontend/` Angular application (to be added)
- `docs/` requirements and design notes

## Running the backend tests
```
cd backend
mvn test
```
